# Digital Image Processing with MATLAB

A collection of Digital Image Processing programs implemented using MATLAB.
This repository contains practical implementations of fundamental image
processing techniques as part of my academic learning and laboratory work.

## 📌 About

This repository includes MATLAB implementations of several fundamental
Digital Image Processing concepts, including image transformation,
enhancement, filtering, histogram processing, bit-plane slicing,
and image detection techniques.

The purpose of this repository is to practice and understand the
fundamental concepts of Digital Image Processing through MATLAB.

## 🧠 Topics Covered

- Image Grayscale Conversion
- Monochrome Image Processing
- Negative Image Transformation
- Log Transformation
- Power-Law (Gamma) Transformation
- Histogram Equalization
- Image Sharpening
- Image Filtering
- Bit-Plane Slicing
- Point Detection
- Line Detection
- Image Zooming and Shrinking

## 📂 Repository Contents

| File | Description |
|------|-------------|
| `grsyscale_image.m` | Converts an image into grayscale |
| `monochrome_image.m` | Converts/processes an image as monochrome |
| `negative_img.m` | Generates the negative of an image |
| `log_transformation.m` | Performs logarithmic intensity transformation |
| `power_law_transformation.m` | Performs power-law/gamma transformation |
| `histogram_equalization.m` | Performs histogram equalization |
| `Sharpen_an_Image.m` | Image sharpening operation |
| `different_filter.m` | Applies different image filtering techniques |
| `bit_plate_slicing.m` | Performs bit-plane slicing |
| `point_and_Line_Detection.m` | Detects points and lines in an image |
| `zooming_and_shrinking.m` | Performs image zooming and shrinking |
